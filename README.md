# PZ Java Mods Setup Manager

Easy setup and repair manager for Project Zomboid Java mods, including ZombieBuddy and Project Viewpoint.

## v1.0.0

The first public release is prepared for Windows x64.

The application helps detect and configure the supported Java mod environment while keeping mod downloads and updates on their official Steam Workshop pages.

### Important

This project does not contain or redistribute ZombieBuddy, Project Viewpoint, Extensions, or their binaries.

Java mod approval remains under ZombieBuddy's security flow and is not bypassed by this manager.

## Download

Use the GitHub Releases section to download the latest Windows build.

## Supported components

- ZombieBuddy
- Project Viewpoint
- Extensions
- ZombieBuddy B42.21 Registration Fix

## Platform

- Windows x64
- Project Zomboid Build 42
- Self-contained .NET 8 desktop application

## Security

The executable is currently unsigned, so Windows may display a SmartScreen warning. Do not disable Windows security protections. Obtain releases only from this repository.
